# Reference verification record

## How these references were found (read this first)

The session that wrote this survey could run **web searches** but could **not open web
pages**. Its network blocked doi.org, arxiv.org, mdpi.com, ieeexplore.ieee.org,
opg.optica.org and the other sites it tried. Each search returned result titles, URLs and
short text summaries, and every reference below comes from those results.

So, for each paper:
- **Checked:** the title, authors, journal, volume, pages and year shown in
  search results from repositories, library catalogues, dblp and arXiv listings.
- **NOT checked:** whether the DOI link resolves, whether the paper is free to read,
  its licence, and its figures. Nobody has opened the publisher's page or the PDF.

Confidence:
- **High:** volume and pages agree in two or more independent records, or come from a
  university repository or dblp.
- **Medium:** one secondary source, or some details missing.
